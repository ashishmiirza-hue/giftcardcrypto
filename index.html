How buying works

  1. Pick a card

    We hold one code for you for 30 minutes while you pay.

  2. Pay the exact USDC amount

    Connect your wallet and approve one transfer on the Base network. Each order has a unique amount, down to the last digit.

  3. We check the blockchain

    Our server confirms the payment on-chain itself. It usually takes under 15 seconds.

  4. Copy your code

    The code appears on screen. Keep the order link to see it again later.

Payments are in USDC on Base. Crypto transfers can't be reversed, so send the exact amount shown. Wrong amount or a problem with a code? Contact support with your order ID.
